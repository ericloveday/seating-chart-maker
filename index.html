How This App Works

Classes

Create one entry per period (New Class). Each class has its own roster, desks, seating, and locks — switching the Class dropdown swaps everything at once. Rename Class lets you change a class's name anytime without touching its roster, layout, or seating. Set your Teacher Name once in the toolbar — it's saved automatically and appears on every printed PDF. Delete Class removes the selected class entirely, including its roster, desks, seating, and locks — this can't be undone.

Adding students

  • Type a name and pick M/F/- (or leave blank), then click + Add Student (or press Enter in the name field).
  • CSV upload format: Last, First, Gender(M/F) — one student per line. A header row (like "Last Name, First Name, Gender") is detected and skipped automatically. The Roster section (Upload CSV / Clear Roster) is near the bottom of the toolbar in Edit Students mode.
  • Click the (M)/(F)/(-) badge on any unassigned student's chip to change their gender anytime.
  • Click a student's name (in the Unassigned list or in a seat) to rename them — renaming doesn't move or unseat them.
  • Clear Roster removes every student from the current class at once (and clears seating too) — handy before uploading a whole new roster, since CSV upload only adds students rather than replacing the list.
  • 🧩 Kagan Group Importer (just below Shuffle in Edit Students mode): opens a separate companion tool in a new tab, signed in with the same account. Give it a CSV of names + test scores and it ranks students, snake-drafts them into balanced 4-person Kagan teams, and seats them directly into this class's existing pod layout — including an H/HM/LM/L role check and a visual map for confirming which desks form each pod before anything is written.

Keep Apart groups

Use 🚫 Manage Keep-Apart Groups (in Edit Students mode) to mark students who should never end up at the same table or right next to each other — the same idea as the bathroom checkout's conflict groups, applied to seating. Check 2 or more students and click Create Group; you can make as many separate groups as you need. 📌 Place Students automatically avoids seating anyone next to a fellow group member whenever it's possible to do so. A manual drag-and-drop can still create one on purpose (for a supervised exception, say) — if it does, that seat gets a red outline and a ⚠️ icon so it's easy to spot before class. Groups are per-class, since rosters are per-class.

Three Views

The room has three modes, switched at the top of the toolbar:

  • 👁 Clean View (the default) — a tidy, read-only look at the chart. No icons, no dragging — great for just glancing at the layout or before printing.
  • 📐 Edit Layout — shows only the table-editing tools (Quick Grid, + Add Desk, Saved Layouts, Select Tables/Duplicate). Every table is freely draggable in this mode, and each table shows its toolbar strip along the bottom (rotate, seats, remove).
  • 🧑‍🤝‍🧑 Edit Students — shows only the student tools (Keep Apart, Place Students/Order, Clear Seats, Kagan Importer, Roster). Tables are fixed in place, each seat shows its toolbar strip along the bottom, and you can drag students from Unassigned onto open seats.

Building desks (Edit Layout mode)

  • Quick Grid: pick rows × columns and seats-per-desk (1 = individual desks, 2 = lab tables), then Generate. This replaces the current layout and clears seating — but never touches your roster, so switching a class from Rows to Groups (or vice versa) is just Generate with new settings.
  • Clear Layout removes every table from the class at once (students return to Unassigned, roster stays intact) — handy when you want to build a custom arrangement from scratch with + Add Desk instead of using Quick Grid.
  • + Add Desk: adds one single desk, draggable immediately.
  • Table toolbar: in Edit Layout mode, the bottom quarter of every table is a toolbar with three buttons, left to right: rotate, seats, and remove.
  • The seats button (chair icon with a number) changes how many seats that table has, 1–6. Students in seats that get removed return to Unassigned.
  • The × removes that table (any seated student returns to Unassigned).
  • The rotate button (↻) turns a table 90° at a time — the whole table, seats, names, and icons all rotate together, so text stays aligned with whichever way the table is facing. Rotating can shift the table slightly (it turns around its center) — just drag it back into place afterward if needed.
  • Select Tables: On lets you click tables to select them (blue outline). Drag any selected table and the whole selected group moves together, keeping their arrangement. Duplicate Selected clones the whole selected group — same layout, same rotations — placed just to the right, and auto-selects the copies so you can keep duplicating to build a row of matching groups fast. Clear Selection deselects everything.
  • While dragging any table, a thin blue guide line appears whenever an edge or center lines up with another table — and the table snaps right into place, just like Canva or PowerPoint.
  • ↔ Spread Out for Square Seats: seats are now bigger squares, so layouts built before that change can have overlapping tables. Click this once per class (and once after applying an older saved layout) to spread every table out proportionally. Seating and locks stay exactly as they were. Rotated tables may need a small nudge afterward.

Saved Layouts (Rows / Groups / etc.)

Build a layout once, then Save Current As... and name it (e.g. "Rows" or "Lab Tables"). Later, pick it from the Saved Layout dropdown and click Apply to drop that same layout into any of your classes. Applying a layout clears current seating for that class. Pick a layout and click Delete to remove it from the list permanently — this only deletes the saved template, not any class currently using that arrangement. Your saved layouts are private to your account, just like your classes.

Seating students (Edit Students mode)

  • Drag a student chip from Unassigned onto any open seat.
  • 📌 Place Students: fills every unlocked seat with unlocked students, using whatever's chosen in the Order dropdown, starting from the front row (bottom of the layout) and working back, and steering around Keep Apart conflicts wherever it can.
  • Order dropdown controls how students get placed: Random (default), or Alphabetical by first/last name — great for a simple, predictable seating chart instead of a shuffle.
  • Alternate gender checkbox: interleaves boy/girl in seat order instead of pure random. Only applies when Order is set to Random.
  • Clear Seats: sends everyone in an unlocked seat back to Unassigned. Locked seats and the students in them stay put, and their locks are kept. To clear everyone, use 🔓 Clear All Locks first. Desks are never touched.

Seat toolbar (visible in Edit Students mode)

Every seat is a square. The top three quarters show the student's name; the bottom quarter is a small toolbar with that seat's buttons:

  • 🔒 / 🔓 (left side of the toolbar, on every seat, filled or empty): click to lock/unlock that seat. Locked seats — whether occupied or empty — turn gold, are skipped by Place Students/Reshuffle, and are protected from drag-and-drop, so you can reserve an empty seat too, not just protect a seated student.
  • The undo arrow (right side of the toolbar, on filled, unlocked seats): instantly sends that student back to Unassigned — use this if drag-and-drop isn't working well on your device (common on touchscreens/Chromebooks).
  • 🔓 Clear All Locks (in Edit Students mode): unlocks every seat in the current class at once, without touching who's seated. Handy if locks ever get "stuck" on empty seats — for example, if Clear Roster is used to wipe students during a roster change, any seats that were locked will be released automatically as of the current version, but this button is here as a quick fix/reset if you ever end up with locked-but-empty seats.
  • ⚠️ (top-right corner of a seat): appears when that seat's occupant is sitting near another student from the same Keep Apart group. Purely informational — it won't block or move anyone, it's just a flag so you notice before class starts.

The toolbar never prints — exported PDFs show just the names.

Locked means locked. A locked student never loses their seat until you unlock it. Place Students and Clear Seats skip them, and any layout change that would delete their seat (Quick Grid, applying a saved layout, Clear Layout, removing their table, or shrinking its seat count) is stopped with a message listing who's in the way. Moving or rotating a table is fine — they ride along with it.

IEP / 504 seating: place the student in the seat they need, click 🔒 to lock it, then hit 📌 Place Students as usual — everyone else fills in around them, and they'll stay locked in for future placements too. Locked students are also excluded from the "Alternate gender" calculation, so they won't throw off the balance.

Exporting

📄 Export PDF opens a small picker so you can choose Landscape, Portrait, or Auto (Best Fit) — Auto captures the current layout and automatically picks whichever page orientation prints it biggest for your specific layout. It adds the class name, your teacher name (if set), and the date/time as the header. The file name includes the date and time too, so it's easy to tell which export is the newest. Seats are shaded by gender (blue for boys, green for girls) both in the app and on the printout. Locked seats show a gold highlight in the app, but print exactly like every other seat, with their normal gender shading. Export PDF works from any of the three view modes.

🔢 Seat Numbers (toolbar, always visible) puts a small numbered badge on the top-left corner of every seat, numbered top-to-bottom then left-to-right across the whole layout. This is the same numbering used on 🏷️ Desk Labels, so "Seat 5" in the app and "Seat 5" on a printed label always mean the same physical seat — handy for matching a sticker to a desk. Desk Labels are formatted for real Avery 58163 sheets (2" x 4" labels, 10 per sheet) and include the class name(s) for that seat plus the seat number.

Seat Roster Report

Pick the classes that share this same desk layout (e.g. Core 1–4). Each physical seat becomes one row, with a column per class showing who sits there.

Keep-Apart Groups

Anyone checked together below will never be placed at the same table or in a touching seat by 📌 Place Students. You can still drag them together yourself — that seat will just show a ⚠️ warning as a reminder.

Migrate Old Data

1. Open Firebase Console → Realtime Database in a new tab (you're already signed into that as yourself — no need to sign in again here).
2. Under seatingCharts, click to expand and open one specific ID — the one holding your old classes (it'll show classes, rosters, etc. directly inside it once you're on that ID's row). Don't export the seatingCharts node itself — go one level deeper, into that specific ID.
3. With that ID's row selected/highlighted, click the ⋮ menu → Export JSON — this downloads a file for just that one ID.
4. Open that file, copy everything, and paste it below.
