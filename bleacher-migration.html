Move bleacher charts into Seating Chart Maker

Copies each bleacher chart into a new class and saves the bleacher layout as “Bleachers.” Nothing in the old bleacher app is changed or deleted.

1. Sign in to both apps

The two apps live in separate Firebase projects, so this page signs into each one.

2. Pick the bleacher charts to move

Each checked chart becomes its own class, with its roster, seats, and locks carried over. Running this again updates the same class instead of making a duplicate.
